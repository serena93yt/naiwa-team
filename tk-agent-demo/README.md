# TK 运营智能体 P0 Demo 使用说明

## 这是什么

本地零依赖 Python 脚本，跑通「①种草生成 + ④合规预检」两个工作流：

> **输入一条中文产品信息 → 输出五国（印尼/泰国/越南/菲律宾/马来西亚）种草文案 + 分镜脚本 + hashtag + 合规三色报告**

## 运行方式

环境：本机任意 Python 3 即可（无需安装任何第三方包）。

```bash
# 1. 默认示例（保湿身体乳，合规版，五国全绿）
python tk_agent.py

# 2. 自定义产品
python tk_agent.py --product "保湿面霜,温和不刺激,补水锁水,89元"

# 3. 违规演示（展示合规守门能力：命中"美白"效果伪造红线 + 广告禁词）
python tk_agent.py --risk

# 4. 微测变体生成（控制变量：只改一个维度，生成多个近似版本）
python variant_generator.py --dimension hook --product "保湿身体乳,温和不刺激,补水锁水,59元"
python variant_generator.py --dimension sellpoint --product "保湿身体乳,温和不刺激,补水锁水,59元"
python variant_generator.py --dimension cta --product "保湿身体乳,温和不刺激,补水锁水,59元"

# 5. 网页卡片渲染
python render_html.py            # index.html（全绿示例）
python render_html.py --risk     # risk.html（标红示例）

# 6. 直播话术（场景二：直播带货，满足「≥2 场景」评分要求）
python live_script.py --product "防晒霜,清爽不油腻,SPF50,69元"

# 7. 测试指标（评审要看：效率/合规命中率/稳定性）
python benchmark.py
```

## 输出说明

- **五国种草内容**：每国包含「种草文案 + 15 秒分镜脚本 + 本土 hashtag」。
- **合规预检报告**：三色标记
  - 🟢 安全
  - 🟡 建议（命中广告禁词，如「最好/第一/100%/根治」）
  - 🔴 必改（命中宗教/文化/政治敏感词）

## 演示脚本（5 分钟）

1. **场景导入**：我是做美妆的跨境商家，主攻 TK 东南亚五国，没有本地母语员工。
2. **工作流一**：运行 `python tk_agent.py`，展示五国种草内容，重点讲「文化适配」——印尼强调 Halal、泰国防晒、菲律宾英语口语。
3. **工作流二**：运行 `python tk_agent.py --risk`，展示合规预检标出「最好/第一/100%/根治」广告禁词，且菲律宾（英文模板）只命中「100%」，体现差异化词库。
4. **总结**：一条产品信息 → 五国内容 + 合规报告，1 分钟完成。

## 合规词库与知识库说明

知识库 `knowledge_base.json` **每条数据均有来源标注**（`meta.数据来源`），详见《可靠数据源清单.md》：

- **合规词表**：依据 TikTok Shop《内容政策(东南亚)》官方红线、印尼《清真产品保障法》、泰国/越南《广告法》等权威源。
- **热门 hashtag**：来自 TikTok 官方披露 + FastMoss/EchoTik 数据（真实标签，非拍脑袋）。
- **市场数据**：Momentum Works & Tabcut 2025 报告。
- **话术模板（hook/cta）**：⚠️ **AI 生成占位，需母语者改写**——这是当前知识库唯一「不可靠」部分，已诚实标注，不冒充本地化权威。

### 可靠性分级

| 字段 | 可靠度 | 说明 |
|---|---|---|
| `compliance` 合规词库 | ✅ 可靠 | 有权威出处 |
| `hashtags_by_category` | ✅ 可靠（美妆类）/ ⚠️ 通用类占位 | 美妆类真实，其他类用通用标签 |
| `sellpoints_by_category` | ⚠️ AI 生成 | 方向对，需母语者润色 |
| `templates` 话术 | ❌ AI 占位 | 明确标注需改写 |

### 合规分类与分级

- **医疗功效/AIGC 效果伪造（🔴必改）**：依据 TikTok 官方红线——「治愈/消除/预防」表述、敏感身体状况（美白/脱发/痤疮）、时间范围暗示。
- **广告绝对化用语（🟡建议）**：依据泰国/越南《广告法》。
- **宗教/文化敏感（🔴必改）**：依据印尼《清真产品保障法》、泰国王室禁忌等。

## 说明

- 这是 P0 原型，用**确定性规则 + 知识库**驱动，离线可跑、演示稳定。
- 真实落地时，种草文案可替换为 LLM 生成（接多语言模型），知识库可继续扩充语料；本 Demo 的核心价值是**展示「文化适配 + 合规守门」的完整工作流闭环**。
