## 「爬公开竞品数据 → AI 洞察 → 选品 + 定价决策」双工作流智能体

> **选题定位（回应主办方三点反馈）**：不再做"又一个大而全的 TikTok 文案工具"（做的人太多、没新意）。转向一个**有数据壁垒、能快速验证现金流、直击省时间**的窄切口——**独立站竞品雷达 Agent**：抓取海外独立站（Shopify/DTC 品牌站）公开可见的竞品数据，用 AI 提炼成"该卖什么、卖多少钱、什么时候上"的选品与定价决策，帮跨境卖家在 1 小时内完成原本 2-3 天的人工竞品调研。

## 二、核心业务场景

### 2.1 一句话定位

**面向独立站跨境卖家，输入一个竞品站或关键词，自动抓取公开可见的竞品数据，AI 提炼成"选品 + 定价"决策，让卖家从"凭感觉铺货"变成"抄对作业"。**

### 2.2 目标用户

| 画像 | 痛点 | 我们的价值 |
|---|---|---|
| Shopify 独立站中小卖家 | 不知道卖什么、定多少钱，靠感觉 | 竞品雷达给出"什么在卖爆、什么价卖得动" |
| 铺货型跨境团队 | 每天盯几十个竞品站，人工看不过来 | 自动监控上新/调价/促销，异常即推 |
| 选品/运营专员 | 竞品调研 2-3 天/次，重复劳动 | 1 小时出报告，专注决策 |

### 2.3 核心业务问题与价值

**问题**：跨境卖家最大的成本不是"没文案"，而是**"选错款 + 定错价"**——选错一款压库存几万块，定错价直接没流量。而竞品数据（谁在卖、卖多少、什么时候上新、怎么促销）官方 API 不给，卖家只能**人工一个站一个站看**。

**价值（量化，可答辩引用）**：
- 47% 跨境卖家每月至少做一次竞品站采集（SellerMotor 2023）
- 用 AI 监控竞品，市场反应速度提升 40%、选品失败率下降 27%（McKinsey 2024）
- 动态调价响应时间从 24 小时缩到 15 分钟（Anker 实测）

### 2.4 触发方式 / 处理逻辑 / 输出形式

| 环节 | 说明 |
|---|---|
| **触发** | ① 粘贴一个竞品站 URL；② 或输入关键词（如 "portable blender"）+ 目标市场 |
| **处理** | 抓公开数据 → LLM 结构化（品类/价格带/上新节奏/促销规律/评论痛点）→ 生成洞察 |
| **输出** | 竞品雷达报告 + 选品建议 + 定价区间 + 合规预检 + Listing 草案 |

## 三、AI 应用 / 智能体设计

### 3.1 预置 AI 团队（即插即用）

| 角色 | 职责 |
|---|---|
| 🔎 **情报员 Agent** | 抓取竞品站公开数据，抽取结构化字段（标题/价格/SKU/上新/促销/评论） |
| 🧠 **分析师 Agent** | 聚类分析：价格带分布、上新节奏、促销规律、差评高频痛点 |
| 💰 **定价军师 Agent** | 结合成本 + 竞品价格带，给出动态定价区间与毛利测算 |
| 🛡️ **合规守门员 Agent** | 检查选品/文案是否踩合规红线（禁词/认证/版权） |

### 3.2 交互方式（对标"像和队友说话"）

商家输入自然语言：
- "帮我看看这个站最近 30 天在卖什么、什么价"
- "我的成本 45 元，这个类目我该定多少价才有竞争力"
- "竞品都什么时候上新、做什么促销，我要不要跟"

Agent 用对话式给出可执行结论，而不是丢一堆原始数据。

### 3.3 双工作流（满足评审"≥2 个工作流，共享上下文"）

**工作流 1：竞品雷达（数据 → 洞察）**
`输入竞品站/关键词 → 抓取 → AI 结构化 → 价格带/上新/促销/痛点洞察 → 雷达报告`

**工作流 2：选品定价决策（洞察 → 赚钱）**
`雷达洞察 → 匹配我的成本/供应链 → 定价区间 + 毛利测算 → 合规预检 → Listing 草案 + 跟进方案`

两个工作流**共享同一份竞品数据上下文**，形成"看清楚 → 下决定"的闭环。

## 四、技术架构与数据壁垒

### 4.1 数据从哪来（核心壁垒，答辩重点）

**关键：官方 API 不提供竞品的实时价格/上新/促销数据，只能从公开页面聚合。这正是"别人没有的数据"。**

| 数据源 | 类型 | 获取方式 |
|---|---|---|
| Shopify 独立站公开页 | 价格/标题/上新/促销标签 | 公开前端抓取 |
| Amazon Best Sellers / 公开 Listing | 热销榜/评论/价格 | 公开页 + 评论聚合 |
| 评论（Yotpo/Judge.me 公开区） | 差评痛点/好评卖点 | 公开评论抓取 + LLM 情感分析 |

**数据壁垒 = 聚合能力 + AI 洞察力**：单条数据人人都能看，但"把 50 个竞品站的价格/上新/促销/评论聚合成一张决策表"是别人没有的。

### 4.2 合规边界（灰，但不越界——答辩话术）

> **"我们抓的是'公开可见、但散落难聚合'的数据，用 AI 把数据变成决策。不碰登录态、不碰个人隐私、不绕过反爬、控制请求频率。灰，但不越界。"**

| 做（安全） | 不做（红线） |
|---|---|
| 抓前端公开数据 | 绕过验证码/登录 |
| 控制频率（≥3s 间隔） | 高频 DDoS 式请求 |
| AI 做结构化 + 洞察 | 抓个人隐私（手机/地址/邮箱） |
| 现场"真爬 + 预置样例"双轨演示 | 原样搬竞品图/文案 |

### 4.3 技术架构（复用现有资产）

```
┌─────────────────────────────────────────────┐
│  前端（单文件 HTML，双击即用）                    │
│  输入竞品站 URL / 关键词  →  雷达报告 / 定价建议   │
└───────────────┬─────────────────────────────┘
                │ POST /chat（Key 不出浏览器）
┌───────────────▼─────────────────────────────┐
│  本地 LLM 代理 proxy.py（复用）                  │
│  转发 OpenAI + 结构化/洞察生成                   │
└───────────────┬─────────────────────────────┘
                │
┌───────────────▼─────────────────────────────┐
│  数据层（三层可靠性模型，复用）                     │
│  L1 本地词库/规则 → L2 公开页抓取 → L3 LLM 洞察    │
└─────────────────────────────────────────────┘
```

**复用现有资产（几乎不浪费）**：
- 本地 LLM 代理 `proxy.py` + `.env` → 原封不动
- `renderData()`（粘贴原文 → LLM 结构化）→ 升级成核心引擎
- `TREND_DATA` / `CAT_TREND` → 改造成"竞品雷达"输出结构
- `checkCompliance()` / FAB 库 → 变成"选品合规预检"弹药
- 五国本地化 → 降级为锦上添花（竞品雷达主打全球/英文）

### 5.1 一句话商业模式

**订阅制竞品雷达：卖家按月付费，换取"自动监控竞品 + 选品定价建议"。**

### 5.2 现金流验证逻辑（回应"快速验证现金流"）

| 收费点 | 单价 | 价值锚点 |
|---|---|---|
| 单次雷达报告 | ¥99-299/份 | 省 2-3 天人工调研，一次回本 |
| 月度订阅（自动监控 N 个竞品站） | ¥299-999/月 | 每天自动盯竞品调价/上新，替代人工 |
| 定制选品+定价咨询 | 按项目 | 高客单增值 |

**对比锚点**（让评委秒懂"值钱"）：
- 人工竞品调研外包：¥500-1500/次，2-3 天
- 第三方数据工具（Bright Data/Apify）：$15-50/GB，还要自己写分析

### 5.3 为什么收费合理（回应"AI 凭什么收钱"）

**因为卖的是"决策"不是"文案"**：文案生成错了顶多重写，选品定价错了压库存亏几万。卖家愿意为"帮我少亏一次钱"的决策付费，且单价天然比文案工具高。
