## 一、文化适配对照表（最强「非直译」证据）

**同一个产品「美白身体乳」，五国差异化表达** —— 证明不是机器直译，而是文化适配：

| 国家 | 核心卖点侧重 | 文化适配点 | 反面（机器直译会犯的错）|
|---|---|---|---|
| 印尼 | 清真认证 Halal + 平价 | 穆斯林占 87%，先讲 Halal 再讲功效 | 直译「美白」→ 踩 AIGC 效果伪造红线 |
| 泰国 | 亮白 + 防晒清凉 | 重颜值 + 防晒场景，轻松幽默 | 忽略防晒场景，只讲「美白」|
| 越南 | 网红同款 + 潮流 | 年轻化、达人背书、性价比 | 用「高端」话术，脱离越南 5 美元价格带 |
| 菲律宾 | 英语口语 + 平价实用 | 96% 销量来自 10 美元以下，极致性价比 | 用书面英语，脱离口语种草语境 |
| 马来西亚 | Halal + 双语 + 极简护肤 | 多元市场、理性消费、84% 详比 | 忽略清真敏感 + 双语需求 |

**一张图看懂「同产品不同文化」**：

```
        美白身体乳（同一产品）
              │
   ┌──────────┼──────────┬──────────┬──────────┐
  印尼       泰国        越南       菲律宾      马来西亚
  Halal认证  防晒清凉    网红同款    budget     Halal+极简
  平价       颜值党      潮流爆款    everyday   双语
```

> **答辩金句**：「机器翻译会把这五个国家翻成五种语言的『同一句话』；我们做的是同一个产品，讲五种『本地人爱听』的话。」

## 二、商业模式（落地可行性 25% 的得分点）

### 2.1 一句话商业模式

**免费获客 + 订阅变现**：免费版每天 5 次生成（获客），Pro 版 ¥99/月（批量 + 直播 + 微测）。

### 2.2 成本对比（企业方评委最吃这一套）

| 方案 | 月成本 | 能做什么 |
|---|---|---|
| 请一个印尼语运营 | ¥8,000/月 | 只懂印尼，一天写不了几款 |
| 请五国运营团队 | ¥40,000/月 | 覆盖五国，但协同成本高 |
| **本产品 Pro 版** | **¥99/月** | 五国五语言 + 合规 + 直播 + 微测，全自动 |

> **成本对比：约 1/80。** 一个 3-15 人的跨境小团队，用 Pro 版的成本是「请一个运营」的 1.2%。

### 2.3 目标市场测算

| 指标 | 数值 |
|---|---|
| 目标客户 | 东南亚跨境中小卖家（3-15 人团队）|
| 市场空间 | 全国跨境卖家数十万级，其中做 TK 东南亚的持续增长 |
| 定价 | 免费 + ¥99/月订阅 |
| 切入策略 | 先打「美妆个护」单一品类，跑通再横向复制（3C/家居/食品）|

### 2.4 为什么收费合理（回应「AI 凭什么收钱」）

1. **省的是人力成本**：不是「翻译」的钱，是「养一个五国运营团队」的钱。
2. **值钱的是知识库**：五国合规词库（带法条出处）+ 文化画像 + 爆款 hashtag，这是持续更新的资产，不是一次性生成。
3. **合规是刚需保险**：踩一次 TK 宗教红线可能封号，¥99/月是「避免封号」的保险费。

## 三、一键启动说明（B 可直接用，D 演示兜底用）

### 3.1 最快演示（无需命令行，双击即可）

**直接双击打开 `index.html`**（保湿身体乳全绿版）和 `risk.html`（违规标红版）——这两个是已经生成好的静态网页，任何电脑浏览器都能打开，**不需要装 Python、不需要联网**。

### 3.2 完整演示（需要 Python 3）

```bash
# 进入目录
cd tk-agent-demo

# 场景一：短视频种草 + 合规预检
python tk_agent.py                              # 默认示例（全绿）
python tk_agent.py --risk                       # 违规示例（标红）
python tk_agent.py --product "防晒霜,清爽不油腻,SPF50,69元"  # 自定义

# 场景二：直播话术
python live_script.py --product "防晒霜,清爽不油腻,SPF50,69元"

# 微测变体（进阶）
python variant_generator.py --dimension hook --product "保湿身体乳,温和不刺激,59元"

# 测试指标（答辩用）
python benchmark.py

# 生成网页卡片
python render_html.py
```

### 3.3 演示兜底（防翻车）

| 情况 | 兜底方案 |
|---|---|
| 现场没 Python | 直接双击 `index.html` / `risk.html`（纯静态网页）|
