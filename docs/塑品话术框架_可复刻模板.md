# 高端塑品话术框架 · 可复刻模板

> 来源：一套被验证"实操性很强"的直播塑品提示词方法论。核心不是"帮我写话术"，而是**一套结构化的塑品公式**，可复刻到任何产品。
>
> 本文档提炼出"可复刻的内核"，并给出「罗马金色耳环」完整示范，供团队照抄、改产品名即可用。

---

## 一、这套框架为什么有效（可复刻的 5 个内核）

| # | 内核 | 公式 | 反例（常见错误） |
|---|---|---|---|
| ① | **卖点 → 场景 → 好处** | 每个卖点必须落到"用户生活场景 + 带来的好处"，不空讲参数 | "925针"只说材质，不说"戴一天不红肿" |
| ② | **反义词痛点** | 每个卖点配一个"反义词 = 痛点坏处"，制造对比 | 只讲"我好在哪"，不讲"不选我损失什么" |
| ③ | **人设定调** | 先锁定"人群 + 风格 + 客单价"，决定语气档次 | 客单价两三百，却喊"家人们冲" |
| ④ | **主次分明** | 一个主卖点打透，次卖点点到为止 | 面面俱到 = 用户一个都记不住 |
| ⑤ | **三段成交收尾** | 比价(给降价理由) + 保障(消除顾虑) + 稀缺(制造紧迫)，各 ≤30 秒 | 全程推销，无节奏感 |

**一句话本质**：普通主播只讲"我的产品好在哪"，这套框架额外讲了"**不选我的你会损失什么**"——这个"反义词对比"才是"越听越想买"的开关。

## 二、可复刻的通用公式（把"罗马金色耳环"换成任何产品）

### 第一步：塑品话术提示词（约 2 分钟）

```
豆包你好，我是一个带货主播，我卖的是【产品名】，你给我写一篇带货话术。

我给你拍张照片，这是我的产品。请你根据这个产品的卖点，依次是：
①【卖点1】②【卖点2】③【卖点3】④【卖点4】

请你按这个顺序，有逻辑地排下来，每一个卖点都要给用户的生活场景带来好处，
一定要有场景代入感。

再推一个反义词——反义词就是痛点坏处。比如：
·【卖点3】对应的是【它的反面/廉价替代】
·【卖点4】对应的是【它的反面/廉价替代】

给我来一篇这样的话术，要求一定要有人味儿，让用户越听越想买。

我的人群是【人群】，风格偏【风格】，客单价【价格区间】，一定要讲得【档次】。
这段塑品话术要在两分钟之内结束，要有一个主卖点，次卖点不要全部写很多。
```

### 第二步：比价 + 保障 + 稀缺（各不超过 30 秒）

```
我挺满意的，继续给我安排比价话术、保障话术、稀缺话术。

比价话术框架：对比市场的高价，给出降价理由——【你的降价理由，如：新号刚开播】。

保障话术框架：用户担心什么？加售后保障、运费险、客户反馈、店铺评分、做了多少年，
给我几个。核心是解决"用户担心我跑了怎么办"。

稀缺话术框架：我剩余很少，为什么少，不拍的损失是什么。

按这三个公式写好，要求有人味儿、不能有营销感、每段不超过30秒、不能啰嗦。
```

## 三、「罗马金色耳环」完整示范（可直接照抄）

### 产品信息卡

| 维度 | 内容 |
|---|---|
| 产品 | 罗马金色耳环 |
| 卖点1 | 外观外形风格（罗马古典金，极简高端）|
| 卖点2 | 搭配（百搭，通勤/晚宴两相宜）|
| 卖点3 | 材质：高温电镀 8 层工艺 |
| 卖点4 | 针：925 银针 |
| 人群 | 资深中产 + 新锐白领 |
| 风格 | 极简高端 |
| 客单价 | 200–300 元 |

### 塑品话术（约 2 分钟，主卖点 = 材质工艺）

> 「姐妹，这副罗马金耳环，你拿在手里第一眼看到的是什么？是它那种**旧罗马金币一样、沉甸甸的金色**，不是那种亮得发贼的廉价黄，是一种很高级的、带着点复古质感的金。上班通勤穿件白衬衫，或者晚上有个饭局换件小黑裙，它都能压得住——**不用换首饰，一副顶三副**。
>
> 但我要跟你讲的重点，不是它好不好看，是**它会不会掉色**。市面上大多数金色耳环，镀的是一层，甚至就喷个金粉，你戴两个礼拜，耳针、耳堵那个地方就开始发黑、褪色，扔了吧可惜，戴着又掉价。
>
> 我们家这副，用的是**高温电镀 8 层工艺**。8 层是什么概念？你把它放到水里泡、洗澡忘了摘、天天戴，它那个金色是**一层一层咬上去的**，不是浮在表面的。你拿到手戴一个月，再拿起来看，还是第一次见它的那个颜色。
>
> 再跟你说一个细节，很多姐妹买耳环最怕什么？**怕过敏、怕耳朵红肿**。那是因为大多数便宜耳环用的是普通合金针，甚至是铁针。我们这副的针，是**925 银针**——就是打耳洞、做真金首饰才用的那个 925 银，戴一天都不会红、不会痒。**敏感耳朵，这个是你唯一该在意的点。**
>
> 所以你看，好看是它的本分，**不掉色、不过敏**才是它值这个价的地方。这副不便宜，两百多块，但你买回去，它不是戴俩月就扔的饰品，是能陪你两三年的那副。"

**结构拆解**（对应公式）：
- 开头 = 卖点1外观 + 卖点2搭配（场景代入：通勤/晚宴）
- 主卖点 = 卖点3高温电镀8层，**反义词 = "一层电镀容易掉色"**
- 次卖点 = 卖点4的925针，**反义词 = "普通合金针过敏红肿"**
- 收尾 = 主次分明（好看是本分，不掉色不过敏才是价值）

### 比价话术（≤30 秒）

> 「同样一副高温电镀8层、925银针的罗马风耳环，你去商场品牌专柜，没有个四五百下不来。我为什么能卖这个价？**因为我这是新号刚开播，就为攒一波口碑和回头客**，利润我基本让出来了。等这波卖完，价格肯定要调回去，趁现在，是真划算。」

### 保障话术（≤30 秒）

> 「你担心什么，我懂。第一，**送运费险**，买回去不喜欢、戴上不合适，退回来一分钱不花。第二，我们**支持七天无理由**，店铺开了好几年，**评分一直 4.9 往上**，回头客一堆。你担心的'拍完人跑了'这种事，在我这儿不存在——我要做的是一辈子的生意，不是一锤子买卖。」

### 稀缺话术（≤30 秒）

> 「这批货我就备了**最后几十副**，为什么少？因为 925 银针 + 8 层电镀，工艺成本摆在那，我不可能一次压太多货。你等下一批，至少半个月，还得是这个价。现在拍的，今天就能发；等没了，就只能看别人戴了。」

## 四、新手上手建议（来自评论区真实反馈）

1. **别一步到位**：新手先从"简单卖点罗列"开始，练熟①卖点→场景→好处，再学②反义词痛点、③人设定调。这套提示词能写清楚，本身说明对产品已经吃透了。
2. **成品要口语化**：AI 生成的句子部分偏书面，直播时把"呈现""体现"这种词，换成"你拿在手里""你看到的"这类口语表达。
3. **反义词是灵魂**：写不出痛点，就想"用户不买我，会去买什么便宜货、然后后悔什么"——那个"后悔点"就是你的反义词。
