## 任务卡 1：五国最新市场数据核实【C 负责】

**为什么做**：方案里引用的 GMV/月活数据是 2025 年的，评委可能问「数据最新吗」。

**具体步骤**：

1. 打开搜索引擎，依次搜这 5 个关键词（每个 10 分钟）：
   - `东南亚 TikTok Shop GMV 2025 2026 报告`
   - `印尼 TikTok Shop 电商规模 最新`
   - `泰国 TikTok Shop GMV 2025`
   - `越南 菲律宾 马来西亚 TikTok 电商 数据`
   - `Momentum Works ecommerce SEA 2025`
2. 优先找这 3 类权威源：**Momentum Works & Tabcut 报告 / TikTok 官方披露 / eMarketer**。
3. 每查到一条，记到下面这个表格。

**产出格式（直接复制这个表）**：

| 指标                  | 数值 | 来源 | 日期 |
| ------------------- | -- | -- | -- |
| 东南亚 TikTok Shop GMV |    |    |    |
| 印尼 GMV              |    |    |    |
| 泰国 GMV              |    |    |    |
| 越南 GMV              |    |    |    |
| 菲律宾 GMV             |    |    |    |
| 马来西亚 GMV            |    |    |    |
| 东南亚月活               |    |    |    |

**验收标准**：至少 4 个格子填了「来源 + 日期」，且来源是权威报告（不是自媒体）。

## 任务卡 2：五国广告禁词核对【C 负责】

**为什么做**：知识库里的禁词我已经查过一轮，但需要你**打开官方规则页逐条核实**，让它「可追溯」更硬。

**具体步骤**：

1. 打开这几个页面（能打开几个算几个）：
   - TikTok 官方《社区准则》：tiktok.com/community-guidelines
   - TikTok Shop《商家内容规则》（搜「TikTok Shop 东南亚 内容政策」）
   - 印尼 BPJPH 清真认证官网（搜「BPJPH halal 认证」）
2. 对照《可靠数据源清单.md》里已经写的禁词，确认「这条词确实在某条规则里」。
3. 每确认一条，在清单里补一个「核对日期」。

**产出格式**：在《可靠数据源清单.md》末尾加一栏：

| 禁词       | 官方依据（哪条规则/法条）  | 核对日期       |
| -------- | -------------- | ---------- |
| 美白（效果伪造） | TikTok AIGC 红线 | 2026-10-2X |

**验收标准**：补了 5 条以上「核对日期」，且能找到官方原文出处。

## 任务卡 3：真实爆款案例采集【C 负责】

**为什么做**：让「场景真实」有实物证据，评委要看「你真的研究过真实爆款」。

**具体步骤**：

1. 打开 TikTok（或抖音国际版网页版），搜你的目标品类关键词（美妆类建议搜 `#skincare`、`#beautytok`、`#glowup`）。
2. 找 2-3 个「东南亚账号 + 高赞」的爆款视频。
3. 每个案例，截图 + 记录下面这套「拆解」。

**产出格式（每个案例一张卡）**：

| 项目      | 内容                    |
| ------- | --------------------- |
| 视频链接    |                       |
| 国家/账号   |                       |
| 点赞/播放量  |                       |
| 品类      |                       |
| 爆点拆解    | 它为什么火？（hook/卖点/情绪/达人） |

## 任务卡 4：母语者校对话术【C 找外援】

**为什么做**：知识库里的 hook/cta 话术是我生成的，标注了「AI 占位需母语者改写」。这是当前唯一「不可靠」的部分，也是最可能被评委抓的点。

**具体步骤**：

1. 去这 3 个地方找人（任选）：
   - Fiverr（搜 `Indonesian proofreading` / `Thai translation`）
   - Upwork
   - 本地大学留学生群 / 语言交换群
2. 发这段英文需求（直接复制）：

> "Hi! I need a native Indonesian speaker to proofread and rewrite 5 short TikTok product scripts (beauty category) to sound natural, not machine-translated. Budget $5 total. Please provide your version. Thanks!"

1. 把知识库里印尼语的 hook/cta 发给他，收回来替换。

**产出格式**：一份「原文 vs 母语者改写版」对照表。

**验收标准**：至少印尼语 1 国完成校对（英语/菲律宾相对简单，有余力再做泰/越）。

> ⚠️ 一周内来不及全做也没关系：**只做印尼语 1 门就够**，其余在 PPT 里诚实标注「其余三国为样板级」。

## 任务卡 5：商家痛点访谈【D 牵头，全组配合】

**为什么做**：评审「真实问题解决度 30%」要看「问题是不是真问题」。有真人证言比任何数据都有说服力。

**具体步骤**：

1. 找 1-2 个做跨境/TikTok 的朋友（没有就问身边做电商的）。
2. 问这 3 个问题，录 30 秒语音或记要点：
   - 「你做 TikTok/跨境，最头疼的是什么？」
   - 「写海外内容，语言和文化是不是个坎？」
   - 「有没有踩过雷（限流/封号/文化冒犯）？」
3. 把原话记下来。

**产出格式**：

| 受访人 | 身份 | 原话（痛点） | 对应我们解决的哪个痛点 |
| --- | -- | ------ | ----------- |
|     |    |        |             |

**验收标准**：1 条以上真实原话，且能对上我们的三大痛点之一。

**为什么做**：我给的「¥99/月」是拍脑袋，需要你基于真实竞品定价校准，别让评委一问就穿帮。

**具体步骤**：

   - `AI 视频脚本生成 定价`

|    |      |      |           |

**验收标准**：3 个竞品以上，且给出了明确的定价结论（维持/调整）。
