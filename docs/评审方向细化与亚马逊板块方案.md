## 二、关键认知：OpenAI 周卡 key 的正确用法

> **OpenAI 的 key 不能「爬数据」，只能「理解/生成文本」。**

真正的实时榜单数据要 EchoTik / Apify / 亚马逊 API（那些也要钱）。周卡 key 能做的是**等价且更聪明的事**：

**把「手动找到的真实榜单」→ 用 LLM 批量转成结构化 JSON → 灌进知识库。**

这就是「数据源真的接进来」的落地方案（图 3 技术评委「应用与数据源连接稳定 20 分 + 应用配置 25 分」最看重）。

## 三、四个动作的详细实现

### 动作 1：降本提效量化（30 分，零成本）

在「💰 算成本」tab 底部新增「AI vs 外包」对比卡片：

| 环节 | 人工/外包 | 出海宝 AI |
|---|---|---|
| 五国文案 | ¥200~500/国 | ≈¥0.1 |
| 五国直播话术 | ¥300/国 | 免费 |
| 出图提示词 | ¥500/套 | 免费 |
| 合规检查 | 1 天人工 | 秒级 |
| 成本核算 | 半天+易漏体积重 | 秒级 |
| **合计** | **≈¥3000 + 3 天** | **≈¥0.1 + 1 分钟** |

**一句话讲清楚**：替换掉「外包翻译 + 本地运营 + 设计师 + 财务核算」四份人力。

### 动作 2：批量生成（明确加分项）

`📦 批量生成` tab：粘贴多行 `品名,卖点,价格`，一键循环生成 N 个产品 × 5 国文案，输出汇总表（每国带合规色标 🟢🟡🔴）。

### 动作 3：数据接入（20~25 分，用周卡，含亚马逊）

`📡 数据接入` tab：粘贴 TikTok/亚马逊真实榜单原文 → 走本地代理调 LLM 抽成结构化 JSON → 同步进爆品区，支持「一键带入生成」。

### 动作 4：对话式改写（15~20 分，用周卡）

`✍️ 改一改` tab：选国家 + 说人话（「语气再活泼点」「改成宝妈人群」「缩短到 30 字」），AI 两轮改写，命中「本地化产出与迭代体验」。

## 四、亚马逊板块的正确切法

**不要**做成另一个完整系统（一周做不完，稀释主线）。

**正确切法**：把亚马逊作为「第二个输出模板 + 一份禁词库」：

- 输入：同一个产品（复用现有 FAB 卖点库 + 品类识别）
- 输出：**Amazon Listing**（标题 + 五点描述 + 后台搜索词 + 合规提示）
- 核心差异点：TikTok 是「情绪钩子 + 冲动下单」，亚马逊是「关键词搜索 + 理性比价」

### 真实数据支撑（可引用到答辩）

- 亚马逊东南亚只有「新加坡站」一个核心站点（amazon.sg），辐射五国配送，无独立泰国/越南站
- 新加坡站客单价 **$48-85**，高于 Shopee 的 **$31**（中高端市场）
- 本地化内容转化率 **+81%**（3.2% → 5.8%）
- 优化标题 CTR **+18%**、五点描述转化率 **+35%**、A+ 页面 AOV **+10.9%**

### 亚马逊绝对化用语红线（已内置检查）

`best`、`#1`、`top-rated`、`number one`、`100%`、`guaranteed`、`cure`、`miracle`、`FDA approved`、`doctor recommended`、`safest` 等，禁止医疗功效和绝对化宣称。

## 六、答辩要点（速记）

1. **降本**：一个商家做五国本地化，原来 ¥3000 + 3 天，现在 1 分钟 + 几毛钱。
2. **数据真实性**：我们不是样例数据，是把真实榜单（TikTok Creative Center / 亚马逊 Best Sellers）用 AI 结构化后接进知识库，有来源、有日期。
3. **全渠道**：同一个产品，TikTok 出「情绪种草」，Amazon 出「理性 Listing」，覆盖「种草→成交」全链路。
4. **可复制**：本地代理 + 相对路径 + 词库与代码分离，换一个品类/平台只是换一套词库，不硬编码。
5. **合规真起作用**：两类校验（内容合规 + 商品认证），两种反馈（🟢🟡🔴 分级 + 逐条提示）。
