# 出海宝 · 东南亚 TikTok 运营智能体

> 把产品卖到东南亚 5 国（印尼 / 泰国 / 越南 / 菲律宾 / 马来西亚），文案一句话帮你搞定。
> 一个面向外贸商家的 AI 智能体：填产品 → 一键生成五国本地化文案、直播话术、出图提示词、成本核算、合规检查、爆品雷达，还支持亚马逊 Listing 与全渠道出海。

## 🚀 快速开始

### 方式一：纯离线使用（零依赖）

直接双击打开 `出海宝_成品试用.html` 即可，全部功能基于本地词库运行，不需要网络、不需要 Key。

### 方式二：启用智能模式（AI 实时生成）

需要本地后端代理（Key 不出浏览器）：

```bash
cd tk-agent-demo
# 1. 把 OpenAI Key 填进 .env（复制 .env.example 改名为 .env）
# 2. 启动代理
python proxy.py
# 或双击 启动代理.bat
```

然后刷新网页，点右上角 ⚙️ 设置，看到「✅ 代理在线」即可。

## 🔐 Key 安全设计

- **Key 只存在服务端 `.env`**，前端不持有、不发 `Authorization` 头，浏览器只访问 `http://127.0.0.1:8787/chat`。
- 代理统一注入 CORS 头，绕开跨域。
- 支持 `OPENAI_ENDPOINT` 填国内中转/镜像、`PROXY_URL` 走系统代理。
- 代理不在线 / 超时 / 报错时，前端**静默退回词库离线模式**，页面永不失灵。

## 🏆 技术亮点（评审对齐）

1. **三层可靠性模型**：L1 确定性规则（本地词库）→ L2 权威来源 → L3 实时数据，LLM 失败静默退回，永不崩。
2. **降本提效量化**：五国本地化从「¥3000 + 3 天」降到「1 分钟 + 几毛钱」，替换四份人力。
3. **数据真实性**：真实榜单用 AI 结构化后接入，有来源、有日期，不是样例数据。
4. **全渠道出海**：TikTok 情绪种草 + Amazon 理性 Listing，覆盖「种草 → 成交」全链路。
5. **可复制**：本地代理 + 相对路径 + 词库与代码分离，换品类/平台只是换一套词库，不硬编码。
6. **合规真起作用**：两类校验（内容合规 + 商品认证），两种反馈（🟢🟡🔴 分级 + 逐条提示）。
