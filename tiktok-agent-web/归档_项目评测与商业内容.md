## 一、量化指标（评审短板①补强 · 量化测试口径）

> 以下为原型模拟口径，用于演示评测维度与可量化闭环；真实接入后替换为线上实测数据。

| 指标 | 数值 | 单位 | 目标达成 |
|---|---|---|---|
| 平均生成耗时 | 2.4 | 秒 / 条 | 88% |
| 合规命中率 | 96.5 | % | 96% |
| 五国覆盖率 | 100 | % | 100% |
| 支持语言数 | 6 | 种 | 75% |
| 规则库条目 | 1240 | 条 | 62% |
| 累计测试用例 | 380 | 个 | 70% |

**指标说明**
- **平均生成耗时**：单次多语言脚本生成端到端耗时，目标 < 3 秒。
- **合规命中率**：预检命中的真实违禁/夸大项占人工复核确认项的比例。
- **五国覆盖率**：已支持本地化生成的东南亚目标市场占比（印尼/泰国/越南/菲律宾/马来西亚）。
- **规则库条目**：跨平台违禁词、类目限制与话术红线条目总量。

## 二、商业模式（评审短板③补强）

- **目标客户**：东南亚五国 DTC / 白牌中小卖家、MCN 与代运营团队
- **价值主张**：把"选题—本地化生成—合规预检—分发微测"做成闭环，降低封号与试错成本
- **收入模式**
  - 基础订阅：按账号数月付，覆盖生成与预检额度
  - 按量抽佣：带货成交 GMV 分成（飞轮闭环）
  - 增值服务：多账号矩阵管理、品牌词库、人工复核
- **成本结构**：多语言模型推理、规则库维护、合规更新人力
- **渠道通路**：TikTok 创作者社群、跨境服务商、SaaS 应用市场
- **护城河**：规则引擎保底 + LLM 增强，先稳后智，现场零依赖可演示
